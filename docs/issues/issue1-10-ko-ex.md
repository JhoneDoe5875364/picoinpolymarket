## 1. 문서의 성격 / 전체 의미

이 문서는 **PredictPix 애플리케이션에 대한 QA 테스트 결과 및 버그 리포트**입니다.
주요 포인트는 다음과 같습니다.

* **로그인 세션 검증 문제**
* **시장 데이터(볼륨, 가격, 트레이드 수 등) 실시간/동기화 실패**
* **계정/포트폴리오 데이터 미표시**
* **어드민 대시보드 API fetch 실패**

즉, **프론트엔드 상태 관리 + 백엔드 API 동기화 + 인증 세션 처리** 전반에 걸친 문제를 보고하고 있습니다.

---

## 2. 섹션별 의미 분석

### ① Main Page (메인 페이지)

**이슈 요지**

* 로그인 세션이 실제로 만료되었음에도 UI 상에서는 로그인 상태로 표시됨
* 특정 액션(구매, 어드민 접근) 시에만 세션 만료가 드러남

**의미**

* 앱 진입 시 **token / session validity check가 수행되지 않음**
* 인증 상태가 **lazy-check** 방식으로 동작하고 있음

**추가 문제**

* Quick Buy 사용 후 앱 재진입 시:

  * Quick Buy 팝업이 정상적으로 dismiss되지 않고 계속 표시됨
* Market Card의 Volume 및 % 수치가 변경되지 않음

  * → 실시간 또는 refresh 로직 누락 가능성

---

### ② Market Card

**이슈 요지**

* 핵심 시장 데이터가 전혀 업데이트되지 않음

**문제 항목**

* Volume
* Traders 수
* Price History
* Recent Trades

**의미**

* Market data polling / websocket / refetch 로직이 작동하지 않거나
* API 응답은 있으나 **state 반영이 되지 않는 상태**

---

### ③ Leaderboard

**이슈 요지**

* 주말 동안 실제로 발생한 트레이드가 리더보드에 반영되지 않음

**의미**

* Leaderboard 집계 로직이:

  * 비동기 업데이트 지연
  * 또는 특정 기간/배치 작업 실패 가능성
* 실거래 데이터와 UI 통계 간 불일치 발생

---

### ④ Account Page (계정 페이지)

**이슈 요지**

* 계정 관련 모든 핵심 데이터가 부정확하거나 비어 있음

**문제 항목**

* In-Play 금액이 틀리고 업데이트되지 않음
* Portfolio & Activity:

  * Open Positions
  * Recent Activity
  * History
    → 전부 빈 화면

**의미**

* Account-related API가:

  * 호출되지 않거나
  * 인증 실패로 인해 데이터 반환 불가
  * 또는 프론트 매핑 실패

---

### ⑤ Admin Dashboard

**이슈 요지**

* 어드민 대시보드 전체가 동작 불가

**구체적 오류**

* Manage Markets → Load failed
* 모든 탭(all, open, pending, resolved, question, status)에서
  **Failed to fetch**

**의미**

* Admin API endpoint 자체 접근 실패
* CORS / 인증 토큰 / API URL / 서버 다운 가능성
* 단순 UI 문제가 아닌 **백엔드 통신 레벨 오류**

## 3. 자연스러운 한국어 번역

### PredictPix 노트 – 1월 10일 / 2026년

**메인 페이지**

* 페이지 진입 시 로그인 상태를 확인하는 체크가 가능한지 궁금합니다.
  오랫동안 앱을 사용하지 않아도 로그인된 것으로 표시되며,
  실제로는 구매나 어드민 페이지 접근 시에야 로그인이 풀린 것이 확인됩니다.
* Quick Buy에서 Yes/No 포지션을 빠르게 구매한 후 앱으로 돌아오면
  Quick Buy 팝업이 그대로 남아 있습니다.
* 마켓 카드의 거래량과 퍼센트 값이 변경되지 않습니다.

**마켓 카드**

* 거래량이 업데이트되지 않습니다.
* 트레이더 수가 업데이트되지 않습니다.
* 가격 히스토리가 업데이트되지 않습니다.
* 최근 거래 내역이 업데이트되지 않습니다.

**리더보드**

* 이번 주말에 진행한 트레이드가 리더보드에 반영되지 않습니다.

**계정 페이지**

* In-Play 금액이 정확하지 않으며 업데이트되지 않습니다.
* 포트폴리오 및 활동 내역:

  * 오픈 포지션
  * 최근 활동
  * 히스토리
    모두 표시되지 않습니다.

**어드민 대시보드**

* Manage Markets 로딩 실패
* 모든 항목(all, open, pending, resolved, question, status)에서
  “Failed to fetch” 오류 발생
